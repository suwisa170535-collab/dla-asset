# ระบบบริหารจัดการครุภัณฑ์และพัสดุคลังย่อย องค์กรปกครองส่วนท้องถิ่น (เทศบาล / อบต.)
### Thai Local Government Asset & Inventory Management System

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการครุภัณฑ์และพัสดุคลังย่อย ออกแบบตามมาตรฐานระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 และหลักเกณฑ์การคำนวณค่าเสื่อมราคาของกรมบัญชีกลาง พร้อมรองรับการเชื่อมโยงระบบบัญชีคอมพิวเตอร์ของ อปท. (e-LAAS)

---

## 🏛️ โครงสร้างและฟังก์ชันสำคัญของระบบ

### 1. ระบบบริหารจัดการทะเบียนครุภัณฑ์ (Asset Management)
- **ระบบนำเข้าข้อมูลจากไฟล์ Excel (Import Excel)**: รองรับการนำเข้าไฟล์ครุภัณฑ์เดิมของเทศบาลสกุล `.xlsx`, `.xls` และ `.csv` พร้อมปุ่มดาวน์โหลดไฟล์แม่แบบมาตรฐาน และระบบตรวจจับคอลัมน์อัตโนมัติ
- **ระบบพิมพ์สติกเกอร์ QR Code ยกชุด แผ่น A4**: เลือกครุภัณฑ์หลายชิ้นหรือทั้งหมดเพื่อพิมพ์สติกเกอร์ลงแผ่น A4 พร้อมรอยประและคิวอาร์โค้ดความละเอียดสูง
- **การออกรหัสครุภัณฑ์อัตโนมัติ**: รันเลขรหัสตามหมวดหมู่ ย่อย และปีงบประมาณ พ.ศ. เช่น `ค.01/2569/001`, `ค.03/2570/001`
- **การบันทึกรายละเอียดเชิงลึก**: ชื่อครุภัณฑ์, หมวดหมู่, ยี่ห้อ, รุ่น, หมายเลขเครื่อง (Serial Number), วันที่ตรวจรับ, แหล่งเงินงบประมาณ (เงินงบประมาณ, เงินสะสม, เงินอุดหนุน), ผู้ขาย/ผู้รับจ้าง
- **ระบบคำนวณค่าเสื่อมราคาอัตโนมัติ (วิธีเส้นตรง Straight-Line Method)**:
  - คำนวณตามเกณฑ์กรมบัญชีกลาง (คิดตามสัดส่วนจำนวนวันในปีงบประมาณแรก 1 ต.ค. - 30 ก.ย.)
  - มูลค่าซากทางบัญชี 1 บาท
  - แสดงตารางแผนค่าเสื่อมราคาสะสมและมูลค่าสุทธิตามบัญชี (Net Book Value) ทุกปีตลอดอายุการใช้งาน
- **ประวัติและตำแหน่งจัดเก็บ**: ระบุสำนัก/กองที่ครอบครอง (สำนักปลัด, กองคลัง, กองช่าง ฯลฯ), ห้อง/สถานที่ตั้ง, และข้าราชการ/พนักงานผู้รับผิดชอบดูแล

### 2. ระบบยืม - คืน ครุภัณฑ์และพัสดุราชการ (Asset Borrow & Return)
- เป็นไปตาม **ระเบียบกระทรวงการคลังฯ พ.ศ. 2560 ข้อ 207-210**:
- บันทึกการขอยืมและออกเลขที่เอกสารคำขอยืมอัตโนมัติ (เช่น `ยค.01/2569`)
- อัปเดตสถานะทรัพย์สินเป็น `ยืมใช้งาน (borrowed)` ทันที ป้องกันการยืมซ้ำ
- ตรวจจับและแจ้งเตือนสีแดงกระพริบเมื่อ "เกินกำหนดส่งคืน"
- บันทึกการส่งคืน ตรวจสอบสภาพ และปลดสถานะกลับมาใช้งานปกติ
- พิมพ์ **"ใบยืม-คืนพัสดุราชการ"** พร้อมข้อตกลงและช่องลงนามถูกต้องตามระเบียบฯ

### 3. ระบบโอนย้ายครุภัณฑ์ระหว่างสำนัก/กอง (Internal Asset Transfer)
- เป็นไปตาม **ระเบียบกระทรวงการคลังฯ พ.ศ. 2560 ข้อ 211**:
- บันทึกการโอนย้ายพัสดุภายในเทศบาลพร้อมออกเลขที่เอกสาร (เช่น `อย.01/2569`)
- โอนย้ายสังกัดสำนัก/กอง, สถานที่ตั้งห้อง และผู้รับผิดชอบดูแลในทะเบียนทรัพย์สินอัตโนมัติ
- พิมพ์ **"ใบส่งมอบ - รับมอบทรัพย์สิน"** พร้อมช่องลงนามผู้ส่งมอบ ผู้รับมอบ และนายกเทศมนตรี

### 4. ระบบบริหารจัดการพัสดุคลังย่อย (Inventory / FIFO Stock Management)
- **การรับ-จ่ายวัสดุสิ้นเปลือง**: ควบคุมสต็อกวัสดุสำนักงาน (กระดาษ A4, หมึกพิมพ์, แฟ้ม, ถุงขยะ, น้ำยาทำความสะอาด)
- **ระบบตัดสต็อกแบบ FIFO (เข้าก่อน-ออกก่อน)**: คุมต้นทุนและอายุของวัสดุตามล็อตที่รับเข้า
- **ระบบแจ้งเตือนจุดสั่งซื้อ (Reorder Point)**: แจ้งเตือนสถานะเมื่อสต็อกต่ำกว่าเกณฑ์ความปลอดภัยทันที
- **การเบิกจ่ายออนไลน์แบบไร้กระดาษ (Paperless Workflow)**:
  - ข้าราชการ/พนักงานยื่นขอเบิกพัสดุผ่านระบบ
  - หัวหน้าฝ่าย/กองพิจารณาอนุมัติทางออนไลน์
  - เจ้าหน้าที่พัสดุกลางจ่ายของและตัดสต็อก FIFO อัตโนมัติ

### 5. ระบบตรวจสภาพ ซ่อมบำรุง และการจำหน่าย (Maintenance & Disposal)
- **การแจ้งซ่อมครุภัณฑ์**: บันทึกประวัติการชำรุด อาการเสีย ผู้แจ้ง วันที่แจ้ง
- **ติดตามงานซ่อมบำรุง**: บันทึกอู่/ร้านที่ส่งซ่อม รายการอะไหล่ที่เปลี่ยน ค่าใช้จ่าย และปรับสถานะครุภัณฑ์อัตโนมัติ
- **การตรวจสอบพัสดุประจำปี (Annual Audit)**:
  - ตรวจนับตามระเบียบพัสดุฯ ข้อ 213 โดยคณะกรรมการตรวจสอบพัสดุประจำปี
  - รองรับการสแกน QR Code / บาร์โค้ดหน้างานผ่านกล้องมือถือ/แท็บเล็ต เพื่อตรวจเช็กสถานะ (ปกติ/ชำรุด/เสื่อมสภาพ/หาไม่พบ)
  - พิมพ์รายงานผลการตรวจสอบพัสดุประจำปีพร้อมช่องลงนามคณะกรรมการ
- **ระบบจำหน่ายพัสดุ (Disposal)**:
  - บันทึกการแทงจำหน่าย 4 วิธีตามระเบียบพัสดุฯ: **ขายทอดตลาด**, **โอน**, **บริจาค**, และ **แปรสภาพ/ทำลาย**
  - บันทึกเลขที่คำสั่งอนุมัติ, วันที่จำหน่าย, เงินรายได้จากการประมูลขายทอดตลาด, ผู้รับโอน

### 6. ระบบรายงานและเอกสารราชการ (Reporting & Forms)
- **การพิมพ์ป้ายสติกเกอร์ QR Code ครุภัณฑ์**: พิมพ์สติกเกอร์ติดตัวทรัพย์สิน พร้อมตราหน่วยงาน, รหัสครุภัณฑ์, ชื่อ, วันที่ตรวจรับ สำหรับใช้สแกนตรวจนับ
- **แบบฟอร์มมาตรฐานราชการ**:
  - **แบบ สท.1**: ทะเบียนคุมทรัพย์สิน (พร้อมตารางค่าเสื่อมราคาและช่องลงนาม)
  - **แบบ สท.2**: บัญชีครุภัณฑ์แยกตามสำนัก/กอง
  - **แบบ พด.1**: ใบเบิกพัสดุราชการ
  - **ใบยืม - คืนพัสดุราชการ** (ระเบียบพัสดุฯ ข้อ 207-210)
  - **ใบส่งมอบ - รับมอบทรัพย์สิน** (ระเบียบพัสดุฯ ข้อ 211)
  - **รายงานผลการตรวจสอบพัสดุประจำปี**
- **รายงานสรุปภาพรวม**: รายงานพัสดุคงเหลือคลังย่อย, รายงานค่าเสื่อมราคาส่งกองคลัง, รายงานการจำหน่ายพัสดุ

### 7. ระบบรักษาความปลอดภัยและการเชื่อมต่อ (Security & Integration)
- **การกำหนดสิทธิ์ตามตำแหน่ง (Role-Based Access Control)**:
  - ผู้ดูแลระบบ (Admin)
  - เจ้าหน้าที่พัสดุกลาง (Central Supply Officer)
  - หัวหน้าสำนัก/กอง (Division Head / Approver)
  - เจ้าหน้าที่ผู้ขอเบิก (Staff)
  - คณะกรรมการตรวจนับพัสดุประจำปี (Audit Committee)
  *(มีระบบ Role Switcher สะดวกต่อการทดสอบกระบวนการทำงานได้ทันที)*
- **ระบบบันทึกประวัติใช้งาน (Audit Trail)**: บันทึกทุกกิจกรรม (เพิ่ม, ลบ, แก้ไข, อนุมัติ, จ่ายพัสดุ, ตรวจนับ) พร้อมระบุชื่อ วันที่ เวลา เพื่อความโปร่งใสและป้องกันการทุจริต
- **การเชื่อมต่อกับระบบ e-LAAS**: ปุ่มส่งออกข้อมูลสินทรัพย์เป็นไฟล์ CSV โครงสร้างมาตรฐานตามระบบบัญชีคอมพิวเตอร์ของ อปท. (e-LAAS) พร้อมรหัสภาษาไทย UTF-8 BOM เปิดใน Microsoft Excel ได้ทันที

## 🚀 วิธีการเริ่มต้นใช้งาน (Quick Start)

### 1. ความต้องการของระบบ (Prerequisites)
- Node.js (เวอร์ชัน 18 ขึ้นไป แนะนำ Node 20 หรือ Node 22+)
- เว็บบราวเซอร์ เช่น Google Chrome, Microsoft Edge, Safari

### 2. ติดตั้งและเริ่มใช้งาน
เปิด Terminal ในโฟลเดอร์โครงการแล้วรันคำสั่ง:

```bash
# ติดตั้งแพ็กเกจ (ทำเฉพาะครั้งแรก)
npm install

# รันระบบ (จะทำการสร้าง Frontend และเปิดเซิร์ฟเวอร์พร้อมใช้งาน)
npm start
```
หรือรันสคริปต์:
```bash
./run.sh
```

### 3. เข้าใช้งานระบบ
เปิดเบราว์เซอร์แล้วไปที่:
👉 **[http://localhost:3000](http://localhost:3000)**

## 💾 การสำรองข้อมูล (Database Backup)
ฐานข้อมูลทั้งหมดจัดเก็บอยู่ในไฟล์เดียว:
`server/database.sqlite`

เจ้าหน้าที่ฝ่ายไอทีของเทศบาล/อบต. สามารถคัดลอกไฟล์ `server/database.sqlite` ไปเก็บไว้ใน Flash Drive, External Harddisk หรือ Cloud Storage ประจำวัน/สัปดาห์ได้ทันทีโดยไม่ต้องติดตั้งระบบฐานข้อมูลภายนอกที่ซับซ้อน
